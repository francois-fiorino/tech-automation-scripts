# Tech Automation Scripts

Repositório de scripts, ferramentas e automações voltados à infraestrutura, cloud computing, engenharia de dados, banco de dados e operações de TI.

O objetivo é compartilhar soluções técnicas, estudos e práticas aplicadas à administração, automação, monitoramento e melhoria contínua de ambientes corporativos.

## Áreas de conhecimento

- **Infraestrutura e Linux:** administração, diagnóstico e automação de rotinas operacionais.

- **Cloud Computing:** estudos e automações para OCI, AWS e ambientes híbridos.

- **Dados e Banco de Dados:** administração, performance, segurança, integração e recuperação.

- **Engenharia de Dados:** pipelines, ETL/ELT, CDC e processamento de dados.

- **Observabilidade:** monitoramento, métricas, logs e diagnóstico de ambientes.

- **Automação:** desenvolvimento de scripts com Python, Shell, SQL e PL/SQL.

## Organização do repositório

Os scripts estão organizados por tecnologia e finalidade, facilitando a consulta, manutenção e reutilização.

O conteúdo será ampliado gradualmente com novos projetos, ferramentas e estudos.

**Tecnologia | Automação | Infraestrutura | Cloud | Dados | Operações de TI**
