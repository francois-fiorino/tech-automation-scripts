All of these scripts are self-explanatory. They are the product of hundreds of hours
of writing custom scripts.

Locating a specific script is easy, using standard OS find utilities (grep, find, etc.).

To find a specific script you can use "grep" or "find". 

For example, to locate all scripts referencing the dba_hist_sysstat table,
you could issue this command:

find . -print|grep -i dba_hist_sysstat *.sql

For Windows users,
you can use the GUI search utility to find a particular script.
